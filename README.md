# 🌐 Portafolio Web

## 📁 Estructura del proyecto

El portafolio está organizado por secciones que muestran diferentes proyectos según la tecnología utilizada. Cada sección incluye una breve descripción, capturas de pantalla y enlaces al código o a una demo funcional (si está disponible).

## 🧭 Cómo navegar

Puedes explorar las siguientes secciones del sitio:

- 🏠 **Inicio:** Presentación personal, skills y resumen profesional.
